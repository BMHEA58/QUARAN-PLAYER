# مشغل القرآن الكريم — Quran Player

مشروع واجهة ويب ثابتة (HTML/CSS/JavaScript) بثلاث لغات: العربية والفرنسية والإنجليزية.

## الوظائف الموجودة
- تحميل القراء والسور من MP3Quran API v3.
- البحث الفوري عن القارئ بالاسم واختيار القارئ والمصحف/الرواية والسورة.
- تشغيل السورة كاملة دون تحديد آيات أو إعدادات تكرار.
- تشغيل الصوت والتحكم بالتشغيل والإيقاف والتقديم والسرعة.
- حفظ ملفات الصوت محلياً عبر Cache Storage إذا سمح الخادم بسياسة CORS.
- Service Worker باستراتيجية network-first لملفات الواجهة عند الاتصال، مع cache fallback عند انقطاع الإنترنت وعزل مخازن التطبيق.
- تصميم متجاوب للهواتف والحواسيب.

## التشغيل محلياً
لا تفتح `index.html` مباشرة عبر `file://` لأن Fetch وService Worker يحتاجان إلى خادم محلي. شغّل مثلاً:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر على Cloudflare Pages
1. اربط هذا المستودع بخدمة Cloudflare Pages.
2. Framework preset: `None`.
3. Build command: اتركه فارغاً.
4. Build output directory: `/` أو `.` حسب واجهة Cloudflare.
5. انشر المشروع.

لا توجد أسرار أو مفاتيح API مطلوبة للمسارات العامة المستخدمة.

## مصدر البيانات وحدود الاعتماد
- مصدر الإنتاج الحالي: MP3Quran API v3.
- توثيق v3: https://www.mp3quran.net/ar/api
- واجهة توقيت الآيات: https://www.mp3quran.org/eng/timing-api
- توثيق v4 التجريبي: https://docs-staging.mp3quran.net/
- v4 غير مستخدم في الإنتاج في هذه النسخة؛ بيئة التوثيق الحالية staging.
- لا تُعد توزيع ملفات الصوت أو تنشرها في خادم آخر. زر الحفظ المحلي يحاول التخزين على جهاز المستخدم فقط، وقد يمنعه CORS أو شروط المصدر.

## الاختبارات والقيود المعروفة

- اختبارات الانحدار: `node --test tests/*.test.mjs`، وفحص الصياغة: `node --check app.js && node --check sw.js`.
- تختبر اختبارات الانحدار البحث عن القراء، واختيار الرواية، وتشغيل السورة كاملة دون تحقق نطاق آيات، واستراتيجية تحديث ملفات الواجهة، واتساق مراجع عناصر الصفحة.
- قد تختلف روابط الصوت وبيانات القراء بحسب المصحف؛ يعتمد بناء رابط MP3 على حقول `server` و`surah_list` الواردة من MP3Quran، ويجب التحقق من توفر الرابط فعلياً لكل قراءة.
- التشغيل في هذه النسخة مخصص للسورة كاملة؛ لا توجد أدوات لتحديد الآيات أو تكرارها.
- حفظ الصوت محلياً يعتمد على CORS ومساحة التخزين وسياسة المصدر. الحفظ داخل Cache Storage ليس ملف MP3 مستقلاً للتنزيل إلى مجلد Downloads.
- قصّ ملف صوتي مستقل (MP3 clipping) وتوقيت الكلمات غير منفذين في هذه النسخة؛ لا يتم توليد روابط قص أو توقيتات غير موثقة.
- الإنتاج الحالي يستخدم MP3Quran API v3. توثيق v4 ما زال خارج مسار الإنتاج الحالي، ولا يتم تفعيل endpoint تجريبي قبل التحقق من استقراره وتوثيقه.
- لا يوجد backend أو حسابات مستخدمين. الواجهة ثابتة وتعتمد على المتصفح وواجهات المصدر العامة.

## النشر

أضيف مسار نشر آلي إلى GitHub Pages عند كل تحديث على فرع `main` عبر `.github/workflows/deploy-pages.yml`. يجب أن تكون خدمة GitHub Pages مفعّلة للمستودع ومصدر النشر مضبوطاً على **GitHub Actions**. نجاح اختبار التحقق لا يعني نجاح النشر؛ راجع سير عمل **Deploy Quran Player to GitHub Pages** للتأكد من اكتمال النشر.

## الترخيص
كود واجهة هذا المشروع مقدم للاستخدام والتعديل. حقوق نصوص القرآن وملفات التلاوة وواجهات API تبقى لأصحابها ومصادرها وشروطهم.

\n## تحديث ملفات الواجهة المؤقتة
- يستخدم Service Worker المفتاح `quran-player-shell-v4` لإبطال النسخة السابقة من ملفات الواجهة.
- عند الاتصال، تُطلب ملفات HTML وJavaScript وCSS من الشبكة مع تجاوز HTTP cache، وتُحدّث النسخة المخزنة بعد نجاح الاستجابة.
- عند انقطاع الاتصال، تُستخدم آخر نسخة مخزنة كخيار احتياطي.
- تشغيل السورة كاملًا ولا يتضمن تحققًا من نطاق الآيات؛ رسائل التحقق القديمة أزيلت من التطبيق.
